- 🔹 **APB-AHB Bridge Verification using UVM**  
  - Designed and verified a bridge to convert AHB transactions to APB operations.  
  - Developed a reusable UVM-based testbench for transaction flow and protocol checks.  
  - Implemented **SystemVerilog Assertions (SVA)** to validate timing and conversions.  
  - Achieved **100% functional & code coverage**.  

- 🔹 **Dual-Port RAM Design & Verification**  
  - Designed a Dual-Port RAM with simultaneous read/write support.  
  - Verified memory behavior using UVM, with directed & constrained-random tests.  
  - Validated corner cases like simultaneous access to same address.  
  - Used **functional coverage & assertions** for data integrity.  

- 🔹 **1x3 Router Design & Verification**  
  - Developed a **1x3 packet-based router** with header-based routing.  
  - Built a **UVM environment** (driver, monitor, scoreboard, coverage).  
  - Verified valid/invalid headers and congestion handling.  
  - Achieved **100% functional coverage**.
